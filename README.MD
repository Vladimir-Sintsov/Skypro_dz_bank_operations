## Описание работы реализованных функций
```
get_mask_card_number(card_number: str) -> str
```
Маскирует номер банковской карты в формате XXXX XX** **** XXXX.
* Вовод: 7000792289606361
* Вывод: 7000 79** **** 6361

```
get_mask_account(account_number: str) -> str
```
Маскирует номер банковского счёта, отображая только последние 4 цифры.
* Ввод: 73654108430135874305
* Вывод: **4305

```
mask_account_card(input_string: str) -> str
```
Автоматически определяет, что маскировать — карту или счёт — и возвращает результат с сохранением типа.
* Ввод: "Visa Platinum 7000792289606361"
* Вывод: "Visa Platinum 7000 79** **** 6361"

* Ввод: "Счет 73654108430135874305"
* Вывод: "Счет **4305"

```
get_date(iso_string: str) -> str
```
Преобразует дату из формата ISO 8601 в формат ДД.ММ.ГГГГ.
* Ввод: "2024-03-11T02:26:18.671407"
* Вывод: "11.03.2024"

```
filter_by_state(operation_list, state='EXECUTED')
```
Фильтрует список операций, возвращая только те, у которых ключ `state` равен заданному значению.

- **operation_list** — список словарей, где каждый словарь описывает операцию.
- **state** — строка, статус операции для фильтрации (по умолчанию `'EXECUTED'`).

Возвращает: список операций с указанным статусом.

```
sort_by_date(operation_list)
```
Сортирует список операций по ключу `date` в порядке от самой новой к самой старой.

- **operation_list** — список словарей операций с ключом `date` в формате ISO.

Возвращает: отсортированный список операций.
