# **Разработка виджета для обработки данных банковских карт и счетов**

## **Функции реализованные в проекте:**

1. функция маскировки номера счета
2. функция маскировки номера карты
3. функция сортировки по дате



## **Требования к проекту**

1. Python 3.12.7
2. flake8 7.2.0
3. mypy 1.16.0
4. black 25.1.0
5. isort 6.0.1


## Инструкция по установке
1. Чтобы скачать репозиторий:
```
git clone git@github.com:Vladimir-Sintsov/Skypro_dz_bank_operations.git
```

1. Установить не обходимые зависимости
```
pip install -r requirements.txt
```
